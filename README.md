# WiseTask — профиль организации

Этот репозиторий содержит страницу организации: [`profile/README.md`](profile/README.md) рендерится на https://github.com/wisetask.

Здесь же могут располагаться общесистемные для организации артефакты GitHub:
- `profile/README.md` — витрина организации,
- `.github/ISSUE_TEMPLATE/` — шаблоны issue,
- `workflow-templates/` — шаблоны workflow для всех репозиториев.
